# ECHO//VOID

A browser-first music survival adventure prototype.

## Core idea

The player is pulled into worlds shaped by music. Calm sections create exploration; intense sections create storms and music monsters. Survival does not require killing everything — running, dodging and escaping are first-class mechanics.

## Prototype

- Medium-sized camera-following battlefield
- WASD / arrow movement
- Sprint and dodge
- Calm → Storm → Chaos waves
- Neon music creatures
- Procedural world variants
- Local audio-file loading
- Lightweight vanilla HTML/CSS/JS architecture

## Planned systems

- Real-time audio analysis (bass / mids / treble / vocal approximation)
- Song structure detection
- World style transformations: 3D, 2D, paper, cartoon, pixel, glitch, realistic, void
- 1000+ world templates and combinations
- Music portals
- Hide / fight / escape systems
- Player progression and story
- Legal custom-music workflow

## Development

No framework is required for the prototype. Open `index.html` in a modern browser or serve the directory with a local static server.
